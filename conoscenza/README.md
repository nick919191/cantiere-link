# Conoscenza · tracciabilità dei materiali da carpenteria metallica

Il metodo, scritto come **regole generali**. Nessun valore, numero, nome di azienda o di cantiere: gli esempi sono
inventati.

Questa cartella è la guida di chi legge le pagine (l’agente con la visione) e di chi scrive le regole Python.
Una regola del codice che contraddice questi file è sbagliata, oppure va cambiato il file.

| File | Che cosa contiene |
|---|---|
| `01_famiglie.md` | le famiglie di documento, come si riconoscono, che cosa portano |
| `02_catena.md` | ruoli, catena a ritroso, chiavi di collegamento, tabella del costruttore, timbri |
| `03_lettura.md` | come si legge una pagina: forma unica della scheda, prova di pagina, casi difficili |
| `04_errori_tipici.md` | gli errori tipici, con la regola che li evita |
| `05_regole_di_stato.md` | PROVATO / DEDOTTO / DA CONFERMARE / MANCANTE |
| `06_excel.md` | che cosa contiene l'Excel |

## Quanto vale
- Le regole vengono dallo studio di alcuni fascicoli reali (qualche centinaio di pagine). Su documentazione diversa
  possono servire regole nuove: le segnalazioni sono benvenute.
- Il risultato è automatico e non certificato: va sempre verificato da un tecnico sui documenti originali.
